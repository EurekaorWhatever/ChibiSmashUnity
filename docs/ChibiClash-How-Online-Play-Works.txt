=====================================================================
  CHIBI CLASH: NETWORK ENGINEERING INFORMATION
=====================================================================

This guide explains how Chibi Clash plays over the internet, in easy
words. Every technical word is explained the first time it is used.


---------------------------------------------------------------------
1. HOW A FIGHT WORKS ONLINE
---------------------------------------------------------------------

* Same fight on both screens.
  Both computers follow the same fight rules, like two people
  following the same recipe. Same buttons in, same fight out on both
  screens.

* Only button presses are sent.
  Your computer just tells your friend's computer "I pressed punch".
  That is tiny, so it is very fast.

* Rollback netcode.
  (Netcode = the part of a game that handles playing over the
  internet.) Messages take a moment to travel, so your game GUESSES
  what your friend will do and keeps going. If the guess was wrong,
  it quickly fixes the screen, so the fight never freezes.

* Version check.
  Before a fight, both games check they are the same version, like
  making sure two people play by the same rulebook. If not, the game
  asks you to update.

* Tested.
  Both screens stay the same even when the internet is slow or loses
  messages.


---------------------------------------------------------------------
2. HOW PLAYERS CONNECT
---------------------------------------------------------------------

* No game server.
  A server is a big computer a company runs to host games. Chibi Clash
  does not need one: the two players' games run the fight themselves.
  This is called PEER-TO-PEER (peer = player, so "player to player").

* Unity Relay = a "post office" run by Unity.
  Home internet blocks strangers from connecting directly, so Relay
  passes the messages between you. It works ANYWHERE IN THE WORLD, on
  any Wi-Fi or phone internet.

* LAN (Local Area Network) = everyone on the SAME Wi-Fi (same house or
  school). Then players connect directly, with no post office needed.

* Leaving a fight:
  - If a player quits, THE OTHER PLAYER WINS.
  - If both get knocked out at the same moment, it is a DRAW.


---------------------------------------------------------------------
3. GAME MODES (ON THE HOME PAGE)
---------------------------------------------------------------------

[ MATCHMAKING ]   Internet needed
  The game finds someone to fight. It looks for players CLOSE TO YOU
  first: your country -> nearby countries -> your continent -> the
  whole world. Closer means less delay.

[ ROOMS ]   Internet needed
  1. Make your own named room.
  2. Your friend joins.
  3. Both pick a character.
  4. Both press OK.
  5. Anyone presses START FIGHT.

[ VS AI ]   NO internet needed
  Fight the computer. The AI (a computer-controlled player) picks a
  random fighter. You press START BATTLE.

[ LOCAL VERSUS / TRAINING ]   No internet needed
  Play on one computer.


---------------------------------------------------------------------
4. PLAYERS
---------------------------------------------------------------------

* First time: the game asks YOUR AGE, then YOUR NAME.

* Your name shows everywhere (menus, fights, rooms, friends, your
  opponent's screen) and is SAVED AUTOMATICALLY on your computer.
  Change it any time with the name button at the top.

* Friends: invite people by typing their name (like Kira#4821).
  A stranger has to say "yes" to being friends first, so nobody can
  spam you.

* Age list: each new player's age and name are saved in a file called
  "player-ages.csv" (a simple table you can open in Excel).
  Every age can play every mode.


---------------------------------------------------------------------
5. SAFETY
---------------------------------------------------------------------

* Rude or fake names are blocked.
* Messages from cheaters or broken games are IGNORED.
* No invite spam, and you can BLOCK annoying players.
* A network expert and a security expert (AI helpers) checked
  everything 5 TIMES, and every problem was fixed.


---------------------------------------------------------------------
6. KEEPING IT SAFE FOR FUTURE WORK
---------------------------------------------------------------------

* Tests = small automatic checks that make sure things still work.
  There are 992, and they ALL PASS.

* Guard tests are like alarms: if someone changes something that
  could break online play, the alarm goes off and explains what to do.

* docs/architecture/netcode/DEVELOPER-GUIDE.md shows which parts are
  safe to change (menus, art) and which parts to leave alone.


---------------------------------------------------------------------
7. CAN MY FRIENDS PLAY WITH ME?
---------------------------------------------------------------------

WORKS RIGHT NOW
  * VS AI, Training, Local Versus: nothing to set up.
  * LAN (same Wi-Fi): works now.

NEEDS SETUP FIRST: internet play (Matchmaking, Rooms, Friends)

  STEP 1: Connect the game to Unity (one time, by the project owner)
    1. Open the game in Unity.
    2. Go to Edit -> Project Settings -> Services, click "Link", and
       pick (or create) a project.
    3. Go to cloud.unity.com, open that project, and TURN ON:
       - Relay   (connects players over the internet)
       - Lobby   (rooms and matchmaking)
       - Friends (friends list and invites)

  STEP 2: Add your friends
    On cloud.unity.com go to "Members" and invite your friends'
    Unity accounts.

  STEP 3: Upload the code
    Upload ("push") the latest code to GitHub (the website that
    stores the code).

  STEP 4: Your friends get the new version
    1. They "pull" (download) the latest code.
    2. They open it in Unity Hub with the SAME Unity version:
       6000.6.7f1
    3. They press Play, choose a name, and play online.

EASIER OPTION FOR FRIENDS WHO ARE NOT DEVELOPERS
  Make a game file (.exe) in Unity (File -> Build) after Step 1, and
  send it to them. They just double-click and play, with no Unity,
  GitHub or setup.

REMEMBER
  * Everyone needs the SAME VERSION of the game, or the fight will
    not start.
  * Test with one friend first, since online play has not been tried
    live yet.
